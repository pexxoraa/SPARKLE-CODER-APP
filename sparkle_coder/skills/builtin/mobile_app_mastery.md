# Mobile App Mastery
Design for touch, intermittent connectivity, lifecycle transitions, constrained resources and platform conventions. Separate persistent domain state from transient screen state. Handle background/foreground, permission denial, deep links and interrupted requests deliberately.

Keep navigation predictable and avoid desktop UI shrunk onto a phone. Use secure platform storage for sensitive local data and minimize permissions. Plan offline/read-through behavior only where it improves the product.

Master standard: critical flows survive rotation/lifecycle/network changes, touch/accessibility behavior is native-feeling, and the app degrades clearly when capabilities or connectivity are unavailable.
