# Typography Mastery
Treat typography as architecture. Choose a display voice and a highly readable supporting voice, then define a small deliberate scale for display, h1/h2, body, caption and navigation. Use fluid sizing where appropriate, controlled line lengths, intentional line-height, and restrained letter-spacing. Do not fall back to plain Arial/Helvetica/default-sans for a premium creative brief.

Headlines should break naturally and create shape; body copy should be easy to scan. Use weight, size, case and spacing to create hierarchy instead of adding boxes, borders or colors everywhere. Avoid tiny uppercase text used excessively, giant headings with no compositional purpose, and inconsistent type values.

Master standard: a screenshot with all images hidden should still feel designed because the typographic hierarchy, spacing and rhythm are strong.
