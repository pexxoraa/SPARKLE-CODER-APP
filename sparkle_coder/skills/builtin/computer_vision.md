# Computer Vision Mastery
Define the visual task precisely: classification, detection, segmentation, OCR, tracking or measurement. Establish annotation conventions, resolution requirements, augmentation and evaluation metrics that match deployment conditions.

Account for lighting, viewpoint, occlusion, class imbalance and camera or domain shift. Preserve calibration and coordinate transforms where measurements or control depend on geometry.

Master standard: evaluation uses representative imagery, preprocessing is identical at inference, failure cases are characterized, and confidence is not treated as guaranteed correctness.
