# Search & Recommendation Mastery
Define user intent, candidate generation, ranking signals and evaluation before implementing search or recommendation. Combine lexical, semantic, behavioral or rule-based signals only when each adds value.

Handle cold start, filtering, diversity and feedback loops deliberately. Measure offline relevance and online user outcomes separately. Avoid personalization that leaks private or cross-tenant behavior.

Master standard: ranking changes can be evaluated reproducibly, results remain explainable enough to debug, and fallback behavior works when signals are sparse.
