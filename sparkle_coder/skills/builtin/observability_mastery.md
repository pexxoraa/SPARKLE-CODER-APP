# Observability Mastery
Instrument around user-visible outcomes and system boundaries. Use structured logs, metrics and traces with stable request or job identifiers. Record enough context to debug behavior without logging private payloads or credentials.

Define service-level indicators for latency, errors, availability and critical business workflows. Alert on symptoms requiring action, not every internal fluctuation.

Master standard: an operator can trace a failed request or workflow across components, dashboards represent user impact, and alerts are actionable.
