# Performance Engineering
Measure or identify the actual bottleneck before optimizing. Reduce duplicated work, excessive I/O, unnecessary model or network calls, oversized payloads and algorithmic waste before applying micro-optimizations.

Preserve correctness under caching and concurrency. Bound memory and output sizes. For frontend work, prioritize loading, layout stability and interaction responsiveness; for backend work, inspect query count, serialization, retries and hot loops.

Master standard: the optimization targets a demonstrated cost, has a before-and-after reason or metric, and does not trade away reliability or clarity.
