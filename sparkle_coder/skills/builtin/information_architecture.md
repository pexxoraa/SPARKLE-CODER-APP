# Information Architecture
Choose page structure based on user needs, not convention. One excellent page is often better than four thin pages. Create multiple pages only when each has enough distinct purpose and content to justify navigation.

For small creative businesses, combine story, services and inquiry on the main experience unless there is substantial portfolio/about content. Navigation labels should be short and specific, current location should be clear when useful, and no page should exist only to contain three paragraphs of filler.

Master standard: every page and section has a unique job, navigation depth is minimal, and visitors never have to hunt for core information.
