# .NET & C# Mastery
Use modern C# with explicit async/await boundaries, cancellation tokens, dependency lifetimes and nullable reference types. Keep domain rules independent from controllers, EF models or UI frameworks where practical.

Avoid sync-over-async, fire-and-forget tasks and accidental multiple enumeration. Make database transaction and object lifetime behavior explicit.

Master standard: async work cancels correctly, resource lifetimes are deterministic, nullable states are intentional, and infrastructure concerns do not own the domain model.
