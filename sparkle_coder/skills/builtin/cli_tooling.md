# CLI Tooling Mastery
Design command-line tools for composability, predictable exit codes and scriptability. Keep stdout for requested data and stderr for diagnostics. Support non-interactive use where practical and never require prompts unexpectedly in automation.

Validate arguments early, provide actionable errors, preserve machine-readable modes and respect signals.

Master standard: commands behave consistently in scripts and terminals, failures are diagnosable, and structured outputs are not mixed with logs.
