# Web Performance Craft
Keep visual quality high without waste. Use appropriately sized local assets, modern image formats when practical, width/height or aspect-ratio to prevent layout shift, lazy loading for below-the-fold imagery, and only the scripts/styles actually needed. Avoid shipping a framework for a simple static experience.

Do not lazy-load the primary above-the-fold hero if it would hurt perceived loading. Prefer CSS for simple effects. Keep font choices disciplined and provide robust fallbacks.

Master standard: the first screen becomes useful quickly, images do not jump the layout, and the project remains small enough to understand.
