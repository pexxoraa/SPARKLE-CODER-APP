# Asset Sourcing
Use project and user-provided assets first. If the experience depends on imagery and no suitable assets exist, use `search_assets` to find reusable Wikimedia Commons candidates with license/creator metadata. Choose only assets that fit the art direction; do not stuff the page with random images. Use `download_asset` to save chosen raster images into `assets/` or another clear project folder, and preserve the source/license note exactly enough for later attribution. Never hotlink a finished portfolio to placeholder services. Never invent a license, creator, or attribution. If no appropriate reusable asset is available, keep an honest asset-ready layout and state the limitation.
