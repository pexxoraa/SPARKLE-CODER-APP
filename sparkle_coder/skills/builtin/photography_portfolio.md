# Photography Portfolio
A photography site sells visual taste. Make imagery the dominant experience: strong hero photography, curated work, intentional crops, generous whitespace, and an editorial portfolio rhythm. Prefer project/user-provided images; never use via.placeholder.com, dummy gray boxes, or fake image URLs as the finished experience. If usable images are unavailable, build a graceful asset-ready layout and state that real photography is still required rather than pretending placeholders are portfolio work. Keep copy brief and specific. Make booking/contact prominent without overpowering the work. Avoid generic slogans such as “Capture Your Moments” unless the user supplied them. Do not hard-code stale years.
