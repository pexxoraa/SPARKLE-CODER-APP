# Accessibility Mastery
Build accessibility into the design rather than adding it afterward. Use semantic landmarks and heading order, meaningful alt text, associated labels, visible keyboard focus, sufficient contrast, logical tab order, and touch targets that remain usable on mobile. Do not use color alone to communicate state.

Decorative imagery should have empty alt text; portfolio images need concise meaningful descriptions when they convey work. Navigation must work without hover. Forms need clear labels, sensible input types, autocomplete where appropriate, useful error affordances, and buttons whose purpose is obvious.

Master standard: the site remains understandable with images unavailable, usable from keyboard, and readable at zoom/mobile sizes without layout breakage.
