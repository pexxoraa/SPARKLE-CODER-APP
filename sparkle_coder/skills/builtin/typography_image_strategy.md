# Typography & Image Strategy
Choose a compact type system before styling: one display character, one readable supporting face or system stack, a deliberate scale, and consistent line-height/letter-spacing. Do not rely on Arial/default sans-serif for a premium visual brief. Use images with a clear role: hero, proof/work, product/property, atmosphere, or supporting detail. Define aspect ratios and `object-fit` intentionally so crops remain strong across breakpoints. Prefer 2–6 excellent images over a noisy gallery. Use CSS variables for the core type, color and spacing system when that keeps the design coherent.
