# Visual QA
Before proposing completion, use `inspect_visual_site` for creative/static web work. It renders desktop and mobile screenshots when Chromium is available and records a deterministic visual-quality gate. Fix blocking findings such as placeholder imagery, missing photography assets, missing responsive intent, stale copyright dates, and broken hierarchy. Use `render_page` when you need an additional desktop/mobile capture after a focused edit. Check hierarchy, spacing consistency, typography, contrast, image prominence, CTA clarity, and obvious generic-template patterns. Make at most two focused polish passes; do not loop endlessly or rewrite everything without evidence.
