# Portfolio Curation
Curate work like an editor, not a file browser. Lead with one signature image or project, then sequence supporting work to create contrast in scale, color, subject and pacing. Do not present six identical thumbnails with labels as the main portfolio experience.

For photography, build a gallery rhythm that can include full-width features, paired images, portrait/landscape contrast, quiet details and project groupings. Captions should add useful context only when needed. If real work is unavailable, create an honest asset-ready composition and say what imagery is needed; never pretend placeholders are a finished portfolio.

Master standard: the order of work feels intentional, there is a clear beginning/middle/end to the visual story, and removing or swapping any image would noticeably affect the composition.
